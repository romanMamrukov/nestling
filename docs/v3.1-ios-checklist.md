# Nestling v3.1 — iOS acceptance checklist

This release is developed separately from the public `main` branch. No storage reset or change to existing sleep-session timestamps is intended.

## 1. Before testing
- Export the current sleep history as a JSON file and retain it in Files or another secure location.
- Use the existing installed Nestling Home Screen app on the same browser profile.
- Do **not** clear Safari website data or uninstall the existing app during testing.

## 2. Manual start time
- Tap **Set sleep start** before beginning a timer. Select a time 15–30 minutes earlier, then save. The running timer should use that earlier start.
- While the timer is active, choose **Adjust start time** to correct it.
- Stop the timer. Verify the saved sleep record uses the adjusted start and current end.
- Attempt a future time, a time over 18 hours earlier, and a start overlapping existing recorded sleep. All must be rejected without modifying the recorded sessions.
- Test **Discard timer**. It should discard the timer only, not finished records.

## 3. Languages
- Switch between English, Latvian, and Russian, reviewing onboarding, Today, History, Insights, Settings, backup messages, alerts and the start-time dialog.
- Verify that chart weekday names, time durations, error messages, settings fields and placeholders use the selected language.
- Export and re-import a backup; the chosen language and backup reminder preference must be restored.

## 4. Local backup reminder
- With a baby profile and at least one recorded session, keep the app active after **20:00 local device time**.
- An in-app backup reminder should appear in Today.
- Select **Later** and confirm it disappears for approximately four hours. This is a reminder, not a background task.
- Select **Export backup**, choose a local save destination, and confirm the JSON is saved outside the browser.
- No automatic file write or server upload should occur. When the app is closed or suspended at 20:00, the reminder may appear only when reopened.
- Setting backup reminders to **Off** suppresses the prompt without affecting manual exports.

## 5. Notifications
- Open Nestling as an **installed Home Screen web app** (not an ordinary Safari tab).
- In Settings, select **Enable device alerts** and accept the iOS permission request. If permission is denied, change it in iOS Settings; the app cannot override denial.
- Use **Test alert** and verify an iOS notification appears. Check Focus, notification authorization and device sound settings.
- While Nestling stays visible and active, create an appropriate predicted nap opportunity. At the chosen reminder offset, the in-app banner should appear and a device notification should be attempted.
- Verify that dismissing the in-app banner does not delete or alter any sleep records.
- **Limit:** Neither an active-tab timer nor a service worker provides reliable scheduled alerts when iOS suspends or closes this server-free app. Closed-app delivery is outside scope.

## 6. Release checks
Run `npm test` locally (Node 18+); this requires no GitHub Actions or paid service. Perform actual iOS checks before merging into `main`. Verify the number of sessions before and after the update, including the most recently recorded sessions.
